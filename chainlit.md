# 🤖 AI-Powered Agentic System

Welcome to your intelligent validation workspace. This AI system helps you run validation operations, track progress, compare results, generate reports, and understand failures faster.

Use direct commands when you know what to run, or ask questions in natural language when you need help, explanation, analysis, or guidance.

## Command Operations

| Command | What it does |
|---------|--------------|
| `copy <baseline>` | Prepare files and inputs |
| `load <baseline>` | Load validation data |
| `branch <baseline>` | Prepare delivery branch |
| `run <baseline>` | Execute the program |
| `unload <baseline>` | Export validation data |
| `compare <baseline>` | Compare actual and expected output |
| `report <baseline>` | Generate a validation report |
| `finalize <baseline>` | Complete delivery steps |

## Smart Workflows

| Command | What it does |
|---------|--------------|
| `validate <baseline>` | Run the full validation flow |
| `reporting <baseline>` | Run the reporting flow |
| `status <baseline>` | Check current progress |
| `list` | View saved sessions |
| `help` | Show available commands |
